# Documentation assets

`workspace.png` is an unmodified capture of the running React interface with the sample
workspace from `src/preview.tsx`, produced by `scripts/check-model-map.py`.

It contains sample agents and connection states, not private accounts or evidence that a
real agent action completed. Keep that distinction in screenshot captions. Do not replace
it with a screenshot containing personal messages, credentials, account details or tokens.

`desktop-workspace.png` is the unmodified desktop screenshot supplied by the project
owner for publication. It shows an example workspace, the Connections panel, and the
desktop status menu, including an attention-required state. Unlike `workspace.png`,
it is not generated from the preview fixtures. Visible agent states are not evidence
that their actions completed successfully.
